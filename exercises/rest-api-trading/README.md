# REST API Design: Stock Trading

Design REST contracts for five actions:

1. `viewStockQuote(symbol)`
2. `viewStockQuotes(symbols)`
3. `placeOrder(symbol, quantity, orderType)`
4. `viewOrder(orderId)`
5. `viewAllOrders(userId)`

Type specs in [`exercise_trading_api.md`](./exercise_trading_api.md) and types in [`trading_api_contract.ts`](./trading_api_contract.ts).
